# Genesis-Driving-intelligence
Driving Intelligence is a Flask-based concept prototype of a Genesis-dedicated driving companion. It recommends roads by a transparent "Fun Driving Score", learns from your driving reports, turns map-API routes into slow/stop/accelerate guidance, shows corner-by-corner cues on a navigation-linked HUD, rewards visits with geofenced stamps and points, and aggregates consented, anonymised data for future high-performance models. It ships with a synthesized engine-start intro, 143 automated tests, and a strict security baseline (CSP without inline scripts, CSRF, parameterised SQL, sanitised uploads).
