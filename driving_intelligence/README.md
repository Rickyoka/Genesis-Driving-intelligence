## v0.8 변경 사항 — 두 줄 라이트 배경 (Deep-space Twin Lines)

제네시스 디자인의 두 줄 램프 모티프를 사이트 전체 배경에 넣었습니다.

- **홈**: 상단 가운데의 먼 광원에서 두 줄짜리 빛 라인 한 쌍이 좌우로 뻗어 나옵니다. 라인은 화면 양쪽 여백에서 아래로 꺾여 푸터까지 이어집니다. 광원 근처에서는 가늘고 희미하다가 가까워질수록 두 줄 간격이 벌어지고 밝아져 원근감을 줍니다.
- **흐르는 빛**: 빛 펄스가 먼 곳에서 출발해 라인을 따라 내려옵니다. 멀리 있을 때는 느리고 가까워질수록 빨라집니다. 별도 같은 광원에서 쏟아져 나오듯 천천히 다가옵니다.
- **다른 페이지**: 광원은 화면 위쪽 바깥에 있다고 가정하고, 양쪽 여백을 따라 내려오는 라인만 보입니다. 화면 전체를 쓰는 도로 렌더러 페이지(`/drive`, `/hud`)에는 넣지 않았습니다.
- **본문과 겹치지 않게**: 라인은 상단의 빈 공간과 양쪽 여백으로만 지나가서 본문 글자를 가리지 않습니다. 세로 화면에서도 같은 규칙을 따릅니다.
- **색**: UI 강조색(코퍼)과 구분되도록, 램프 라인은 차가운 화이트·블루 계열 빛으로 표현했습니다.
- **성능·메모리**:
  - 라인 형태는 화면 크기나 레이아웃이 바뀔 때만 계산하고, 매 프레임에는 스크롤 위치만큼 옮겨 그립니다.
  - 고해상도 화면에서는 렌더링 해상도를 1.5배로 제한합니다.
  - 탭이 숨겨져 있거나 시동 인트로가 화면에 있는 동안에는 그리지 않습니다.
  - 페이지를 떠날 때 애니메이션과 감시 객체를 모두 해제합니다.
  - 측정 결과: 스크롤하며 10초 넘게 돌려도 JS 힙이 약 1 MB에서 늘지 않았습니다.
- **접근성**: `prefers-reduced-motion` 환경에서는 움직임 없이 정지 화면만 그리고, 스크롤할 때만 다시 그립니다. 장식 요소라 `aria-hidden` 처리했고, 인쇄할 때는 숨깁니다.
- 시동 인트로의 바닥 라이트도 같은 두 줄 모티프로 바꿨습니다.
- 관련 파일: `app/static/js/cosmos.js`, `app/templates/base.html`(`cosmos` 블록), `app/templates/index.html`(`data-cosmos-anchor`), `app/static/css/style.css`

## v0.7 변경 사항 — 시네마틱 시동 인트로

앱을 처음 열 때(세션당 1회, `?intro=1`로 다시 보기 가능) 나오는 시동 인트로를 새로 만들었습니다. 소리와 화면이 같은 rpm 곡선을 공유하기 때문에, 엔진음이 커지는 순간 타코미터 바늘도 함께 튀어 오릅니다.

| 시점 (버튼 누른 후) | 화면 | 소리 (ICE 기준) |
|---|---|---|
| 0 ms | START·STOP 버튼이 눌려 사라지고, 충격파 링과 라이트 블레이드가 퍼짐 | 버튼 클릭음 |
| 0.25 s | 계기판이 그려지고 바늘이 끝까지 갔다 돌아오는 셀프 테스트, 중앙 패널에 SYSTEM CHECK | 스타터 크랭킹 |
| 0.9 s | 중앙 패널이 READY로 바뀌고 차량명·엔진명 표시 | 점화 · 저음 쿵 |
| 1.3 s | rpm 바늘이 약 4,400까지 튀었다가 아이들링으로 내려옴 | 블립 · 오버런 팝 |
| 1.4 s | 차량이 어둠 속에서 밝아지고 차체 윤곽을 따라 빛이 지나감 | 아이들링 |
| 2.3 s | DRIVING INTELLIGENCE 타이틀이 한 글자씩 나타남 | 아이들링 |
| 4.3 s (EV 3.8 s) | 줌인과 블러로 전환되며 홈 화면이 열림 | 페이드아웃 |

- **EV 차량**(GV60 마그마 등)은 RPM 대신 POWER % 게이지와 함께 신스 패드, 터빈 상승음, 3음 차임이 나오고 패널에 POWER ON이 뜹니다.
- **사운드**는 녹음 파일 없이 Web Audio API로 합성합니다(오실레이터, 웨이브셰이퍼, 필터, 컴프레서, 리버브). 모든 게인은 0에서 시작하도록 명시해, 재생 첫 프레임에 큰 소리가 튀는 문제를 막았습니다. 재생이 끝나면 AudioContext를 닫아 메모리를 남기지 않습니다.
- **화면 크기**: 가로 화면에서는 게이지·패널·게이지를 한 줄로, 세로 화면(휴대폰·태블릿)에서는 게이지 두 개 아래에 패널을 두는 배치로 자동 전환합니다.
- **접근성**: `prefers-reduced-motion` 환경에서는 파티클과 애니메이션 없이 완성된 READY 화면을 잠시 보여 주고 바로 넘어갑니다. 건너뛰기 버튼과 Esc가 항상 동작하며, 사운드 켜기/끄기 설정은 브라우저에 저장됩니다.
- **정리**: 인트로가 끝나면 requestAnimationFrame, 타이머, 키 이벤트, 오디오를 모두 해제하고 DOM에서 제거합니다. CSP를 지키기 위해 인라인 스크립트나 style 속성은 쓰지 않았습니다.
- 관련 파일: `app/static/js/intro.js`, `app/templates/base.html`(인트로 마크업), `app/static/css/style.css`(intro 섹션)

## v0.6 추가 기능 — 내비 연동 HUD (감속·가속 가이드)

`/drive` (메뉴: **HUD 주행**) — 내비게이션이 계산한 경로의 코너 정보를 HUD가 실시간으로 받아 지금 무엇을 해야 하는지 앞 유리에 띄웁니다. 실사형 도로 장면도 실제 코너 데이터에 맞춰 휘어집니다.

### 공도 · 리듬 모드
코너마다 아래 단계를 거리와 목표 속도로 안내합니다.

| HUD 표시 | 의미 |
|---|---|
| **감속 준비 235 m** (주황) | 250 m 전부터 남은 거리 표시 · 목표 속도 · 코너 방향·강도 |
| **감속 → 42 km/h** | 직선에서 감속을 끝낼 구간 |
| **코너 · 일정한 속도** (하늘색) | 브레이크·가속 없이 차로 안에서, 시선은 출구로 |
| **출구 · 부드럽게 가속** (초록) | 제한속도까지 천천히 회복 |
| **♪ 리듬 구간** (보라 배너) | 250 m 이내 간격으로 코너가 3개 이상 이어지는 구간. 흐름이 가장 즐거운 곳 |
| **정지** (빨강) | 출발·체크포인트·도착 |

**재미의 기준은 흐름입니다.** 권고 속도는 승차감 기준(횡가속 0.2 g) 상한이며 제한속도를 넘지 않습니다. 이 모드에는 더 빨리 달리게 하는 안내가 없습니다.

### 서킷 모드 (폐쇄 코스 전용)
- 브레이킹 보드 **150 / 100 / 50 m** → **BRAKE** → **TURN IN** → **APEX** → **THROTTLE** → **FULL** 순으로 안내하고, 랩 타임과 최고 랩을 표시합니다.
- 계산은 등록 차량의 출력·중량·구동 방식과 타이어 선택(스트리트 0.95 g / 세미 슬릭 1.15 g)으로 합니다. 접지 한계 횡가속, 0.9 µg 제동, 출력과 공기저항으로 제한되는 가속을 반영해, 3바퀴를 이어 계산한 플라잉 랩입니다.
- **잠금:** "폐쇄 서킷에서만 사용" 확인 전에는 재생할 수 없습니다. 실서비스에서는 등록된 서킷 지오펜스 안에서만 활성화하는 구조를 전제로 합니다.
- **가상 서킷:** 데모 서킷(3.6 km, 9개 코너: 에스, 스위퍼, 헤어핀, 시케인)은 가상 코스입니다. 직선 길이를 조정해 루프가 정확히 닫히도록 만들었고, 코너 반경은 설계값 그대로입니다. 실제 서킷을 쓰려면 측량 형상 데이터와 강사 검증이 필요합니다.

### 구현 (`app/services/corner_engine.py`)
- **코너 검출:** 회전 반경 250 m(서킷 200 m) 미만인 연속 구간을 하나의 코너로 묶습니다. 방향이 바뀌면 별도 코너로 나눠 S자 코너를 구분합니다.
- **단계 위치:** 속도 프로파일에서 감속 시작점, 턴인, 에이펙스(최저 속도), 가속 시작점, 출구를 찾습니다. 16개 코스 전체에서 단계 순서가 어긋나지 않는지 테스트합니다.
- **API:** `/api/route-guide` 응답에 `corners`, `rhythm`, `curv`를 추가했습니다. `/api/circuit-guide?tyre=street|semi`를 새로 추가했습니다.

### 이미지 업로드 보안
- 파일 이름이나 MIME 형식이 아니라 Pillow로 **실제 디코딩**해서 형식을 판별합니다. 허용 형식은 JPEG·PNG·WebP이며, 해상도 폭탄(4,000만 화소 초과)은 거부합니다.
- 모든 이미지를 **WebP로 다시 저장**합니다. 이 과정에서 EXIF(촬영 위치 GPS, 기기 정보)가 지워지고, 이미지 안에 스크립트를 숨긴 파일(폴리글랏)도 무력화됩니다. 긴 변은 1,800 px로 줄여 저장합니다.
- 저장 파일명은 무작위 UUID이며, 정규식으로 검사한 이름만 제공합니다. 경로를 조작해 다른 파일을 읽을 수 없습니다(테스트로 확인).
- 사진을 교체하거나 차량을 삭제하면 기존 파일도 함께 지웁니다. 업로드는 CSRF 보호 대상이며 이미지 사용 권한 확인 체크가 필요합니다.
- 파일 위치: `instance/uploads/vehicles/`.

### 이미지 사용 권한
제네시스 공식 이미지(보도자료·미디어 사이트 등)를 쓰려면 해당 사이트의 이용 조건을 확인하세요. 시연·제안 자료에는 직접 촬영한 사진이나 사용 허락을 받은 이미지를 권장합니다. 이 프로젝트에는 제네시스 차량 이미지나 디자인을 포함하지 않았습니다.

## v0.4 추가 기능 — 지도 API 경로 가이드 (감속 · 정지 · 가속 구간)

`/route` (메뉴: **경로 가이드**) — 지도·경로 API로 받은 실제 도로 형상과 교차로 정보로 구간별 운전 가이드를 만듭니다.

| 구간 | 색 | 의미 |
|---|---|---|
| **감속** | 주황 | 곡선·교차로·정지 지점 전에 미리 줄이기 시작하는 구간. "감속 시작 → 30 km/h 이하 · 반경 35 m 우커브 · 70 m 동안" 식으로 안내 |
| **정지** | 빨강 | 출발, 체크포인트(전망·스탬프), 도착, T자 교차로 일시정지 |
| **가속** | 초록 | 코너·교차로를 벗어나 **제한속도까지** 부드럽게 회복해도 되는 구간 |
| **정속** | 파랑 | 일정한 속도 유지 |

**화면 구성:** 색으로 구간을 칠한 지도(출발 S·체크포인트·도착 E 마커는 끌어서 조정 가능) · 구간 안내 목록(클릭하면 지도 이동) · 거리별 권고 속도 그래프 · *주행 재생*(차량 아이콘이 경로를 따라 움직이며 미니 HUD에 현재 구간과 다음 안내 표시) · 감속 여유 설정(기본 0.20 g / 여유 0.15 g) · 예시 제한속도 선택.

### 계산 방식 (`app/services/route_guide.py`)
1. **경로 API:** 출발 → 체크포인트 → 도착을 OSRM(OpenStreetMap 기반) Route API로 요청합니다(`overview=full`, `steps=true`). 결과는 `instance/route_cache/`에 저장해 같은 경로는 다시 요청하지 않습니다.
2. **곡률:** 경로를 10 m 간격으로 나누고 앞뒤 30 m 세 점으로 회전 반경을 계산합니다.
3. **권고 상한 속도:** `min(제한속도, √(횡가속 한도 × 반경))`. 횡가속 한도는 0.20 g(여유 모드 0.15 g)로, 차량 성능 한계가 아닌 **승차감·안전 여유 기준**입니다. 반경 35 m에서는 약 30 km/h, 70 m에서는 약 42 km/h입니다.
4. **교차로·정지:** API가 준 회전 지점은 20~25 km/h, T자 교차로·출발·체크포인트·도착은 0 km/h로 제한합니다.
5. **감속·가속 계산:** 뒤에서 앞으로 감속 1.5 m/s², 앞에서 뒤로 가속 1.0 m/s² 한도를 적용해 "어디서부터 줄이고 어디서부터 다시 올릴지"를 정합니다. 이 한도를 넘지 않는다는 것을 테스트로 확인합니다.
6. **파워트레인별 문구:** 전기차는 "회생제동 단계를 올려 감속", 내연기관은 "가속 페달에서 발을 떼고 엔진 브레이크로 감속"으로 안내합니다.

### 안전 원칙
- 권고 속도는 **넘지 말아야 할 상한**이며 도달 목표가 아닙니다. 도로 표지·노면·날씨·교통이 항상 우선합니다.
- 가속 구간은 제한속도까지만 안내합니다. 설정은 더 보수적으로(0.15 g)만 바꿀 수 있고, 높이는 옵션은 없습니다(서버에서 거부, 테스트로 보장).
- 브레이킹 포인트·레이싱 라인 같은 서킷 전용 성능 코칭과는 별개인 공도용 안전·승차감 안내입니다.

### 지도·경로 API 설정
| 변수 | 기본값 | 설명 |
|---|---|---|
| `DI_ROUTE_PROVIDER` | `osrm` | `osrm` 또는 `offline`(시뮬레이션 경로만) |
| `DI_OSRM_URL` | OSRM 공개 데모 서버 | `{coords}` 자리에 `lng,lat;lng,lat` 형식의 좌표가 들어갑니다. 자체 OSRM 서버 주소로 바꿀 수 있습니다 |
| `DI_MAP_TILE_URL` | `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | 지도 타일. 이 주소의 https 호스트만 CSP `img-src`에 자동으로 허용됩니다 |
| `DI_MAP_ATTRIBUTION` | `© OpenStreetMap contributors` | 지도 저작권 표기 |

- **인터넷이 없을 때:** 경로 API에 연결하지 못하면 코스 특성으로 만든 **시뮬레이션 경로**로 자동 전환하고 화면에 알립니다. 실패 후 60초 동안은 API를 다시 부르지 않아 화면이 느려지지 않습니다. 지도 타일만 실패하면 배경 없이 경로와 구간은 계속 표시됩니다.
- **운영 전 교체 권장:** OSRM 공개 데모 서버와 OSM 타일 서버는 가벼운 시연용입니다. 운영 시에는 자체 OSRM 서버나 국내 상용 경로 API(카카오모빌리티, TMAP 등)와 타일 서비스로 바꾸고, 각 서비스의 약관과 키 발급 절차를 따르세요. 경로 조회 기능(Provider)은 `route()`만 구현하면 교체할 수 있습니다.
- **제한속도:** 현재 화면에서 고르는 예시 값입니다. 실서비스에서는 도로 링크별 제한속도 데이터와 연동해야 합니다. 고도 데이터를 연동하면 내리막 감속 안내도 더 정확해집니다.
- **지도 라이브러리:** Leaflet 1.9.4(BSD-2-Clause)를 `app/static/vendor/leaflet/`에 포함했습니다. 외부 CDN을 쓰지 않습니다.
- **출발·도착 좌표:** 코스별 출발·도착 지점은 근사값입니다. 지도에서 마커를 끌어 조정하면 즉시 다시 계산합니다.

### 스탬프·포인트 규칙과 안전장치
- **중복 지급 불가:** 모든 적립은 고유 키(`stamp:코스`, `set:컬렉션`, `milestone:개수`)로 원장에 기록되고 DB `UNIQUE` 제약이 걸려 있어, 같은 보상이 두 번 지급될 수 없습니다. 적립은 방문 기록과 함께 하나의 트랜잭션으로 처리됩니다.
- **재방문:** 방문 횟수만 기록하고 포인트는 주지 않습니다. 10분 안의 반복 체크인은 같은 방문으로 봅니다.
- **위치 검증:** 정확도 ±300 m를 넘는 위치는 거부합니다. 직전 체크인 지점에서 시속 250 km 이상으로 이동해야 가능한 체크인은 보류합니다(위치 조작 1차 방어). 서버가 반경을 다시 계산하므로 브라우저 값만으로는 적립되지 않습니다.
- **개인정보:** 위치 좌표는 **저장하지 않습니다**. 어느 체크포인트를, 어떤 방식(휴대폰 GPS / 차량 GPS / 시연)으로, 언제 방문했는지만 기록합니다(테스트로 보장).
- **안전:** 포인트는 방문에만 주어지고 속도·주행 시간·도로 위험도와는 무관합니다. 운전 중 휴대폰 조작 금지를 안내합니다.
- **위치 권한 조건:** 브라우저 위치 기능은 **HTTPS 또는 `localhost`**에서만 동작합니다. 휴대폰으로 같은 네트워크의 PC에 접속해 시연하려면 HTTPS 설정이 필요하며, 그렇지 않으면 시연 모드를 쓰세요. 보안 헤더는 `Permissions-Policy: geolocation=(self)`로 같은 사이트에만 위치 권한을 허용합니다.
- **한계:** 웹 앱은 화면이 열려 있을 때만 위치를 확인합니다. 실서비스에서는 백그라운드 위치(모바일 앱) 또는 차량 GPS(커넥티드 서비스)로 체크인하고, 실제 제네시스 멤버십 포인트 체계·약관과 연동해야 합니다.
- **좌표:** 체크포인트 좌표는 **근사값**입니다. 실서비스 전 현장 측량이나 지도 API로 검증하고, `app/data/courses.json`의 `checkpoint` 항목(좌표, `radius_m`)을 수정하세요. 국내 범위를 벗어난 좌표는 시작할 때 오류로 걸러집니다.

5-0. `경로 가이드` → 지도에서 감속·정지·가속 구간 확인
5-1. `HUD` → 코너 예고·회생제동 안내 재생

8. `파트너십`, `경쟁 비교`로 사업 전략 마무리

## 3. 점수 로직

### Fun Driving Score (코스)

구성 요소(0–100)를 모드별 가중치로 합산한 뒤 차량·날씨·시간대 보정을 더합니다. **모든 보정 내역이 화면에 표시**되므로 결과를 추적할 수 있습니다.

| 구성 요소 | 산식 | Sport | Touring | GT |
|---|---|---|---|---|
| 운전 재미 | 곡률 45% + 헤어핀 25% + 고저차 30% | 40% | 15% | 15% |
| 주행 편안함 | 노면 50% + 도로 폭 30% + 한산함 20% | 15% | 20% | 35% |
| 경관 | 경관 등급 | 10% | 30% | 15% |
| 휴게·편의 | 시설 등급 | 5% | 15% | 10% |
| 안전 여유 | 100 − 위험도 | 20% | 15% | 15% |
| 모드 적합 거리 | Sport 5–30 km, Touring 10–60 km, GT 30 km+ | 10% | 5% | 10% |

- **차량 보정:** 대형·중량 차량 + 좁은 길 −10, 중량 차량 + 연속 헤어핀 −6, 후륜 + 노면 불량 −5, GT 모드 + 중량 차량 + 여유 도로 +4, 경량 차량 + 연속 코너 +3
- **날씨:** 비 −(2×곡률 + 2×헤어핀), 후륜 −3 추가 / 눈·결빙 시 동절기 주의 구간은 **추천 제외**, 나머지 −15 (AWD −8)
- **야간:** 야경 코스 +3, 조명 부족 코스 −10
- **원칙:** 출력·최고속도는 점수를 올리지 않습니다 (테스트 `test_speed_is_never_rewarded`로 보장).

### 주행 분석

| 지표 | 입력 | 프로토타입 규칙 |
|---|---|---|
| 가속 제어 | 종방향 가속도 | 급가속(> 0.30 g) 빈도/10 km, 가속 저크 P95 |
| 제동 안정성 | 종방향 가속도 | 급제동(< −0.35 g) 빈도/10 km, 제동 저크 P95 |
| 조향 일관성 | 횡방향 가속도 | 횡방향 저크 P95 (입력의 매끄러움) |
| 코너링 안정성 | 횡방향 가속도 | 급선회(> 0.40 g) 빈도, 횡가속도 P95 |
| 차간거리 유지 | — | 레이더·ADAS 데이터 필요 → **평가하지 않음** (추정하지 않음) |

- 신호는 0.5초 이동평균으로 평활화하고, 이벤트는 히스테리시스(임계값의 70% 아래로 내려가야 재감지)로 중복 집계를 막습니다.
- 5초 넘게 비는 구간은 계산에서 제외합니다. `accel_long_g`가 없으면 속도 변화로 계산합니다.
- **모든 임계값·계수는 시연용**입니다. 실차 텔레메트리와 강사 검증 데이터로 보정해야 합니다.

### CSV 형식

```csv
timestamp_s,speed_kmh,accel_long_g,accel_lat_g,heart_rate_bpm
0.0,0.53,0.146,0.008,74
0.1,1.06,0.145,-0.014,74
```

필수: `timestamp_s`, `speed_kmh` · 선택: `accel_long_g`, `accel_lat_g`, `heart_rate_bpm` · UTF-8 / CP949(엑셀) 인코딩 지원 · 최대 20만 행 · 최소 30행·1 km

### 학습형 내비 규칙

| 학습 신호 | 반영 방식 |
|---|---|
| 최근 리포트 5건의 제동·코너링 평균 < 70 | 운전 재미 가중치 −10%p → 안전 여유 +10%p (위험도 낮은 코스 우선) |
| 종합 지표가 꾸준히 80 이상 (2건 이상) | 안전 여유 −5%p → 운전 재미 +5%p |
| 저장 코스의 공통 유형 (상위 2개) | 해당 유형 코스에 최대 +4점 |

가중치 합은 항상 100%로 유지되며(테스트로 보장), 학습 보정은 코스 상세의 점수 구성에 그대로 표시됩니다.

### Magma 데이터 랩 원칙
- **동의 기반:** 기본값은 미동의. 동의·철회는 언제든 가능하며 철회 시 개인 집계 내보내기가 차단됩니다(403).
- **최소 수집:** 리포트의 점수·이벤트 빈도·차종만 사용. 위치·시간·주행 궤적은 집계와 내보내기에서 제외합니다.
- **소그룹 비공개:** 5건 미만 차종 그룹은 통계에 표시하지 않습니다.
- **합성 데이터 표기:** 데모 플릿은 시연용 합성 데이터이며 화면·JSON 모두에 명시합니다.

## 4. 보안·안정성 설계

- **CSRF:** 모든 POST에 세션 토큰 검증 (`hmac.compare_digest`)
- **XSS:** Jinja2 자동 이스케이프, 인라인 스크립트 없이 **CSP `script-src 'self'`**, JSON 데이터는 실행되지 않는 `application/json` 블록으로 전달
- **SQL Injection:** 모든 쿼리 파라미터 바인딩, DB 레벨 `CHECK` 제약 추가
- **입력 검증:** 길이·범위·화이트리스트 검증, 제어 문자 차단, 필터 파라미터는 허용값 외에는 기본값으로 대체
- **업로드:** 크기 한도(413), 확장자·인코딩·행 수 검증, **파일을 디스크에 저장하지 않고** 메모리에서 분석 후 결과만 저장
- **헤더:** CSP, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`, HTTPS일 때 HSTS
- **세션 쿠키:** `HttpOnly`, `SameSite=Lax`, 선택적 `Secure`
- **신뢰 경계:** 교육 기록의 `verified`(공식 수료)는 사용자가 설정할 수 없음 (위조 요청 테스트 포함)
- **인트로·HUD 스크립트:** 오디오 컨텍스트는 재생 후 닫고, 타이머·리스너는 종료 시 해제. HUD 재생은 탭이 숨겨지면 자동 정지
- **CSP 준수:** 인라인 스크립트·인라인 스타일 0개 (테스트로 보장). 인트로 깜빡임 방지는 외부 `boot.js`로 처리
- **리소스:** 요청별 DB 연결을 teardown에서 반드시 닫음, 데이터 파일은 시작 시 1회 로딩 후 불변 객체로 공유, 외부 CDN·폰트 의존성 없음
- **오류 처리:** 사용자에게는 안전한 메시지만, 상세 내용은 로그 파일에 기록
