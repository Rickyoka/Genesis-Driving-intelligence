    리듬 모드: 재미의 기준은 '흐름'

    1. 감속 준비 → 감속: 코너 전 직선에서 감속을 끝냅니다. HUD가 감속 시작까지 남은 거리와 목표 속도를 보여줍니다.
    2. 코너 · 일정한 속도: 코너 안에서는 브레이크도 가속도 하지 않고 같은 속도로, 차로 안에서 시선은 출구로 둡니다.
    3. 출구 · 부드럽게 가속: 코너가 풀리는 지점부터 제한속도까지 천천히 가속합니다.
    4. 리듬 구간: 짧은 간격으로 코너가 3개 이상 이어지는 구간입니다. 이 흐름을 끊김 없이 이어 갈 때 와인딩이 가장 즐겁습니다.

    권고 속도는 승차감 기준(횡가속 0.2 g)의 상한이며 제한속도를 넘지 않습니다. 이 모드는 더 빠른 주행을 안내하지 않습니다.

    {% else %}

    서킷 모드 안내 단계

    1. 150 · 100 · 50: 브레이킹 포인트까지 남은 거리 보드
    2. BRAKE: 직선에서 강하게 제동, 진입 속도까지
    3. TURN IN: 스티어링 시작
    4. APEX: 코너 최저 속도 지점, 클리핑 포인트
    5. THROTTLE → FULL: 스티어링을 풀면서 가속, 직선에서 풀 스로틀

    차량 출력·중량과 타이어 접지(0.95 / 1.15 g)로 계산한 이상적 랩입니다. 실제 코칭은 텔레메트리와 전문 강사 검증 데이터로 보정해야 합니다(Phase 4). 데모 서킷은 가상 코스입니다.

    내비 ↔ HUD 연동 구조

    • 내비게이션: 경로 API → 10 m 간격 곡률 → 코너별 감속 시작·턴인·정점·가속 지점 계산
    • HUD: 현재 위치 기준으로 다음 코너의 단계·남은 거리·목표 속도를 표시, 단계별 색 변화
    • 차량 데이터: 실제 속도와 권고 속도의 차이, 감속 시작 시점을 주행 분석·학습 루프로 환류
    • 모드 분리: 공도는 리듬 모드만, 서킷 모드는 폐쇄 코스 확인 후에만 활성화
